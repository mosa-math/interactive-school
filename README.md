# منصتي التفاعلية — المرحلة الأولى لمساحة عمل المعلم

من الكتاب إلى التحضير، ثم المحتوى والتقويم. واجهة عربية RTL دون حسابات في المرحلة الأولى.

## البداية

1. افتح الكتب الدراسية، واختر كتاب الرابع أو السادس للفصل الأول، أو أرفق كتابك المحلي.
2. استخدم الكتاب لتحضير درس، وحدد عنوانه وصفحاته (حتى ٨ صفحات لكل طلب). راجع الترقيم والنص والصور.
3. من أداة العرض اضغط ولّد عرضًا، أو من بنك الأسئلة ولّد أسئلة، أو من الاختبارات/أوراق العمل استخدم زر التوليد الخاص بها. كل طلب يتطلب موافقة استهلاك API والتحقق.
4. احفظ الأسئلة في البنك وصنّفها بالدرس والمهارة. ابنِ اختبارًا أو ورقة عمل أو تحديًا من المحدد دون تكلفة API جديدة.
5. عدّل النتيجة وراجع الإجابات، ثم اطبع نسخة الطالب ونموذج الإجابة المنفصل أو نزّل العرض المستقل.

الكتابان الأصليان المقدمان من المستخدم متاحان كمرفقات إصدار GitHub `textbooks-1448-term1`، وتخدمهما نقطة `/books/` في Worker كتدفق دون تحميلهما كاملين في ذاكرة الخادم. `books/` يحتوي الفهرس والأغلفة فقط. لم يُعدّل ملفا PDF، ولا يستدعي تحميلهما OpenAI. الكتب المضافة يدويًا والدروس تبقى في المتصفح؛ لا يرسل التوليد إلا الصفحات المختارة. لا يوجد بحث دلالي تلقائي عن عنوان درس داخل الكتاب الكامل.

## التحضير والمحتوى والتقويم

- التحضير: الكتب، تحضير الدروس، الخطة الأسبوعية وتوزيع المنهج المحليان القابلان للتعديل والطباعة.
- المحتوى: عروض بالصور والشرح التدريجي والقلم، ألعاب من بنك الأسئلة، وفيديو MP4/WebM محلي بأسئلة توقف عند توقيتات محددة. الفيديو وأسئلته لا تُرسَل إلى خدمات خارجية؛ أعد اختيار الفيديو واستورد JSON الخاص بأسئلته لكل جلسة جديدة. أسئلة الفيديو تُضاف يدويًا، وليست مولّدة من الصوت.
- التقويم: بنك مصنف حسب الصف والدرس والمهارة، تصفية وتحرير واستيراد/تصدير، بناء اختبار أو ورقة من المحدد، ومسودتان منفصلتان لكل درس. حتى ٤٠ سؤالًا للمستند.
- لا يوجد قسم مستقل للذكاء الاصطناعي. أزراره داخل الأدوات. المسارات القديمة محفوظة للتوافق.
- قائمة جانبية للحاسب وسفلية للجوال. مجموعات التنقل وتفصيل الملفات في [ARCHITECTURE.md](ARCHITECTURE.md).

الصفوف والطلاب وملخص الأداء مؤجلة حتى تسجيل الدخول وقاعدة محمية. أدوات الحصة وملف الشواهد وتنظيم النسخ الاحتياطي والإعدادات مرحلة لاحقة. الصفحة الرئيسية الحالية تعريفية؛ حصص اليوم والتنبيهات لم تُنفّذ.

## التخزين والحدود

الكتب والدروس في IndexedDB، والبنك والخطط في localStorage. لا مزامنة أو حسابات. صدّر دروسك وبنكك وأسئلة الفيديو، واطبع الخطة PDF، واحتفظ بالكتب الأصلية. لا تُحذف بيانات الأدوات السابقة تلقائيًا. مكتبة الأسئلة حتى ٢٠٠٠ سؤال والخطط حتى ٣٠٠ بند.

تحقق برمجي لعمليات الضرب المرفقة فقط. القراءة البصرية والنص والمهارات والإجابات تحتاج مراجعة المعلم. لا يوجد ضمان آلي لمطابقة المنهج أو صحة كل مسألة. الاختبارات المحاكية لا تثبت جودة مخرجات OpenAI الحقيقية. لم نُجرِ توليدًا مدفوعًا أثناء التطوير.

## الخدمة والنشر

GitHub Pages: الفرع `main` وجذر المستودع. ارفع البنية كاملة بما فيها `features/` و`books/` و`vendor/`.

Cloudflare Worker: نفس خدمة interactive-school-api وأسرار `OPENAI_API_KEY` و`TURNSTILE_SECRET_KEY`. يُسمح للمصدر `https://mosa-math.github.io`، وTurnstile لنفس المضيف، والنموذج `gpt-4o-mini`.

```sh
npx wrangler deploy --config server/wrangler.toml
node --test tests/*.test.mjs
```

`config.js` يحتوي رابط الخدمة ومفتاح Turnstile العام فقط. لا تضع مفتاح OpenAI في أي ملف عام. ملفات `server/` المنشورة لا تحتوي أسرارًا. نقاط `/v3/prepare` و`/v3/worksheet` و`/v3/test` تدعم التوليد المباشر، و`/v3/outline` و`/v3/lesson` للتوافق مع المخطط، و`/generate` للأداة القديمة.

الحماية: تحقق Origin وTurnstile، حدود حجم وطلبات، مراجع صفحات ومخطط JSON، `store:false`، وعدم تنفيذ HTML الناتج. الخدمة بلا حسابات؛ أي زائر يجتاز التحقق يمكنه التوليد. حدود ٣ طلبات/دقيقة لكل عنوان و٢٠ طلبًا/دقيقة تقريبية على حافة Cloudflare، وليست سقف إنفاق عالميًا صارمًا. المصادقة مطلوبة لحصرها بمعلمين محددين في المرحلة التالية.
