منصتي التفاعلية — الإصدار الأول

الملفات:
index.html — الصفحة الرئيسية
style.css — التصميم
app.js — جميع الوظائف التفاعلية

النشر على GitHub Pages:
1. أنشئ مستودع GitHub جديدًا (Public).
2. ارفع الملفات الثلاثة إلى جذر المستودع، وليس ملف ZIP.
3. من Settings > Pages اختر Deploy from a branch ثم main و /(root) واحفظ.
4. افتح الرابط الذي يظهر بعد اكتمال النشر.

الخصائص: عروض قابلة للتعديل، كتاب صفحات، تحديات فريقين، اختبار مصحح تلقائيًا، إضافة أسئلة، نسخ احتياطية JSON.
ملاحظة: هذه نسخة أولية مستقلة ولا تتضمن توليد فيديو أو ذكاء اصطناعي. البيانات تحفظ في localStorage على الجهاز نفسه ولا تنتقل تلقائيًا بين الأجهزة.
