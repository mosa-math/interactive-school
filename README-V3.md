# الإصدار الثالث — منصتي التفاعلية

هذه نسخة كاملة جاهزة للمراجعة والتحديث فوق الموقع الحالي. لا تحتاج بناء للواجهة. تحافظ على الأدوات الأربع ومحرر الإصدار الثاني ومفاتيح التخزين السابقة، وتضيف «مساحة الدروس» في #workspace. لا تنفذ التحديثات أو الترحيل تلقائيًا عند فتحها.

## ما أُنجز

- مكتبة دروس وكتب محلية في IndexedDB. الكتاب PDF محفوظ في المتصفح حتى ٢٠٠ ميغابايت؛ لا يرفع إلى خادم.
- فتح PDF كامل واختيار حتى ٨ صفحات للدرس، مع فرق ترقيم بين الملف والكتاب، ومعاينة الصفحات واستخراج النص محليًا. يظهر الفهرس إذا كان PDF يحتوي فهرسًا مضمّنًا. لا يوجد اكتشاف مضمون آلي للفصول.
- اقتطاع صور وأمثلة أصلية من الصفحات محليًا، واختيارها لكل شريحة وتكبيرها. دعم صور صفحات PNG/JPEG/WebP كذلك.
- مراجعة المصدر ثم مخطط وأهداف قابلة للتحرير؛ بناء شرائح يدوي مجاني أو طلب مدفوع للمخطط ثم طلب مستقل بعد الاعتماد للشرائح.
- قوالب للغلاف والأهداف والشرح والأمثلة والأنشطة والتقويم والخلاصة، بهويتين فاتحة وداكنة. الأهداف تسبق الشرح. حدود لطول النص والخطوات في التوليد والتحرير.
- درس موحد يضم المصدر والأهداف والصور والأسئلة. أسئلة الدرس نفسها في تبويب الأنشطة والعرض. نسخ اختياري مؤكد للأدوات الأربع السابقة؛ ينبه لاستبدال بياناتها ولا ينفذه تلقائيًا.
- عرض الحصة بملء الشاشة، وخطوات بالنقر، وقلم ومسح، وأسئلة وتفسير. الأسهم للتنقل والمسافة للكشف.
- حفظ محلي، واستيراد وتصدير درس JSON بصوره، وتنزيل عرض HTML مستقل يعمل دون إنترنت ويحتوي صور المصدر والقلم والأسئلة. التوليد يحتاج إنترنت؛ ليس حفظ الموقع كله دون اتصال.
- تحقق حسابي لعملية الضرب الصحيحة المرفقة بالشريحة، وتحذير عند تعارض الناتج أو خيار عددي صحيح. لا يوجد محرك يتحقق من كل مسألة لفظية أو معادلة في الكتاب.
- نموذج جاهز لدرس ٥–٦ للصف الرابع ص ١٥٧–١٦٠: ١٢ شريحة، الأهداف في البداية، وصور أصلية من الكتاب. لم يُرسل الكتاب أو الدرس لطلبات API أثناء التطوير.

## طريقة التجربة

شغّل من هذا المجلد:

```sh
python3 -m http.server 8766
```

ثم افتح http://localhost:8766/#workspace. اختر «درس الكتاب الجاهز • دون تكلفة». جرّب الأهداف وصور المصدر والشرح المتدرج والأسئلة. افتح «الكتاب والمصدر» لإضافة ملفك الكامل وتحديد صفحاته. رقم ١٥٧ في ملف الكتاب المستخدم يطابق الرقم المطبوع؛ الكتب الأخرى قد تختلف.

لا تفتح index.html مباشرة كملف: وحدات JavaScript وPDF.js تحتاج خادم HTTP أو GitHub Pages. العرض المستقل الذي تنزّله من داخل المحرر يمكن فتحه مباشرة دون خادم أو إنترنت. lesson-demo.html أيضًا معاينة مستقلة للدرس السابق، وليس محرر الإصدار الثالث.

اختبر ملف العرض المستقل بعد تنزيله على الجهاز الذي ستستخدمه في الحصة. زر طباعة المتصفح يطبع جميع الشرائح؛ ليس تصدير PowerPoint قابلًا للتحرير.

## استخدام AI وتكلفته

config.js يحتوي رابط Worker ومفتاح Turnstile العام فقط. لم يُضف API key إلى أي ملف عام. التكلفة غير ثابتة: الصور والنص والمخرجات تُحتسب حسب المزود. في واجهة المخطط يجب تفعيل خانة الموافقة ثم تأكيد الطلب. يُعاد طلب الموافقة لكل مرحلة. يُرسل النص والصفحات المختارة والمخطط فقط، لا ملف الكتاب الكامل. يمكن إلغاء إرفاق الصور والاكتفاء بالنص المصحح.

بعد الاستجابة تسجل أعداد input/output tokens في الدرس. التكلفة بالدولار من لوحة استخدام OpenAI. قد تُحتسب الطلبات غير المكتملة أو التي انتهت مهلة اتصال المتصفح بها؛ راجع الاستهلاك قبل تكرارها. الموافقة المرئية جزء من تجربة الاستخدام، وليست تفويضًا ماليًا خادميًا أو سقف تكلفة صارمًا.

لم يُختبر التوليد الحقيقي للمرحلتين حتى لا يُستهلك الرصيد دون موافقة. اختبارات المزود محاكية. الخطأ أو الرقم غير الواضح في PDF يحتاج تصحيح المعلم؛ لا يقدم النظام شهادة بصحة المحتوى أو مطابقته الكاملة للمنهج.

## النشر والتحديث

1. صدّر بيانات الأدوات القديمة من الرئيسية، واحتفظ بنسخة من المستودع الحالي.
2. ارفع ملفات هذه النسخة إلى جذر interactive-school مع الحفاظ على بنية vendor وserver وtests. لا ترفع ملف ZIP بدل فكّه. PDF الكتاب الكامل غير مضمّن ولا يرفع للمستودع. النموذج المرفق يحتوي الصفحات الأربع وصورها فقط.
3. تبقى GitHub Pages على main و/(root). افتح /interactive-school/#workspace بعد اكتمال البناء. شغّل تحديثًا كاملًا للصفحة إذا بقيت ملفات قديمة.
4. إعداد Cloudflare السابق يستمر: نفس Worker ونفس أسرار OPENAI_API_KEY وTURNSTILE_SECRET_KEY ونفس Rate Limit bindings. من مجلد النسخة شغّل:

```sh
npx wrangler deploy --config server/wrangler.toml
```

5. لا تعِد إدخال الأسرار في config.js ولا تحذفها من Cloudflare. نقطة /generate القديمة محفوظة، والجديد /v3/outline و/v3/lesson. السماح للمصدر مضبوط على https://mosa-math.github.io (دون مسار المستودع).
6. قبل الاستخدام المدفوع، تأكد من رصيد API والصلاحيات ونفّذ اختبارًا واحدًا بموافقة المعلم.

حدود الأمان: الخدمة تحمي المفتاح بـWorker وتفرض Origin وTurnstile وحدود الحجم والطلبات، وتتحقق من المخطط والمراجع والاستجابة، ولا تنفّذ HTML من المحتوى. لا يوجد تسجيل دخول للمعلم أو مزامنة سحابية في هذه النسخة. أي زائر ينجح في التحقق يمكنه استخدام التوليد؛ إن أردت حصره بمدرسة/معلمين محددين، يلزم إضافة مصادقة قبل نشر رابط الخدمة لجمهور واسع. حدود Cloudflare موزعة تقريبية وليست سقف إنفاق عالميًا صارمًا.

## الحفظ والاستيراد

الكتب والدروس محلية لهذا المتصفح وهذا النطاق. قد تُمسح عند تنظيف بيانات الموقع؛ ليست نسخًا سحابية. تنزيل JSON يحفظ الدرس وصفحاته وصوره، ولا ينسخ ملف الكتاب الكامل. حذف ملف كتاب من المكتبة لا يحذف صور المصدر المحفوظة بالدروس. حد الاستيراد ٢٥ ميغابايت، والحد الأقصى ٢٠ صورة مقتطعة و٢٠ شريحة. اختر معلمين فقط لاستخدام الملفات المحلية الحساسة، ولا تُدخل بيانات الطلاب في المصدر.

## التحقق

```sh
node --test tests/*.test.mjs
node --check workspace.mjs
node --check app.js
node --check server/worker.mjs
```

اجتازت اختبارات المصدر والأرقام العربية، والتحقق الحسابي وتعارض الخيارات، وموافقة الاستهلاك، ورفض URL للصور، وCORS والأحجام والطلبات، والتوليد المحاكي، والتصدير دون روابط API. اختُبر فتح ملف الكتاب الفعلي (نحو ١٢٣ ميغابايت و١٩٩ صفحة) محليًا ومعاينة ص ١٥٧، والحفظ والمخطط والقوالب والعرض. لا تدّع الاختبارات المحاكية أنها توليد فعلي.

## المكتبات والمراجع

PDF.js في vendor، بإصدار محدد في vendor/VERSION.txt وترخيص Apache-2.0 المرفق؛ الموارد مضمّنة محليًا. لا توجد CDN لتشغيل PDF.

- https://mozilla.github.io/pdf.js/examples/
- https://developers.openai.com/api/docs/guides/images-vision
- https://developers.openai.com/api/docs/guides/structured-outputs

للتراجع أعد ملفات الإصدار الثاني من نسختك أو Git. تظل بيانات IndexedDB للإصدار الثالث معزولة عن بيانات الأدوات القديمة.

## الكتب والأوراق والاختبارات
من مكتبة الكتب اختر الرابع أو السادس والفصل الدراسي ثم أرفق PDF حتى ٢٠٠ ميغابايت. الكتب تبقى في متصفحك ولا تُنشر في GitHub. فتح كتاب من المكتبة يبدأ درسًا جديدًا لمنع خلط المصادر. حدد صفحات الدرس وراجعها؛ لا يوجد فهرس دلالي تلقائي للكتاب الكامل.
من أوراق العمل والاختبارات الفترية حرر أسئلة الدرس أو اجمع أسئلة دروس من الصف نفسه. يُجمع السؤال المرتبط بصفحة مصدر، ويحتاج مراجعة المعلم للمطابقة واكتمال المعطيات وعدم كشف الإجابة في سياق الشريحة. يمكن إضافة أسئلة مقالية ودرجات وزمن ومدرسة ومعلم، حتى ٤٠ سؤالًا.
احفظ المسودة ثم نزّل نسخة الطالب ونموذج الإجابة منفصلين بصيغة HTML. افتحهما واختر طباعة أو حفظ PDF. لا تتضمن نسخة الطالب مفتاح إجابة مخفيًا. هذه الإضافة لا تستدعي OpenAI، ولا تقدم تصحيح المقال أو تحليل النتائج. تصدير الدرس JSON يحتفظ بالمسودة.
